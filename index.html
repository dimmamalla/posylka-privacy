Политика конфиденциальности

Посылка
Дата публикации: 21 сентября 2026 г.
Оператор: физическое лицо
Контакт: dim.gons@yandex.ru

1. Общие положения

Приложение «Мои Посылки» помогает пользователю хранить трек-номера посылок и просматривать их статусы на устройстве. Используя приложение, вы соглашаетесь с этой политикой.

2. Какие данные обрабатываются

  • трек-номер и название посылки, которые вы вводите сами;
  • служебные сведения об устройстве, необходимые для работы приложения;
  • при подключении рекламы — рекламный идентификатор устройства.

Мы не создаём аккаунт, не запрашиваем ФИО, телефон, паспорт и геолокацию.

3. Где хранятся данные

Трек-номера и названия сохраняются локально на вашем устройстве.

4. Для чего данные нужны

  • показать список ваших посылок;
  • обновить статус по запросу;
  • показывать рекламу, если она включена в вашей версии.

5. Передача третьим лицам

Данные не продаются. Рекламная сеть может получать технический идентификатор устройства. Если позже подключится сервис статусов, трек-номер уйдёт только туда.

6. Права пользователя

Удалите посылку в приложении или само приложение — локальные данные сотрутся. Вопросы: dim.gons@yandex.ru.

7. Дети

Приложение не предназначено для детей младше 13 лет.

8. Изменения

Актуальная версия публикуется по этому адресу.
